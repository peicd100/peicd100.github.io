轉換規則 v1（第一種純文字題目 → 第二種：Markdown + TTS 標記 + 答案標記 + 文法強調）

0) 參數（外部資料；可選）
- ANSWER_KEY（可選）：{題號: "A"|"B"|"C"|"D"}，用來標記正確選項。
- HIGHLIGHT_MAP（可選）：{題號: [片語1, 片語2, ...]}，用來在題幹內強調指定片語。
- ANS_PREFIX：正確選項的前綴字串（建議用純 ASCII，例如 "*"）。

1) 前處理（Normalization）
1.1 全文換行統一為 \n
1.2 去掉每行行尾空白
1.3 連續 2 行以上空白行壓成最多 1 行空白（避免過多空段）

2) 題目區塊切分（Segmentation）
用下列標頭作為切分點，把全文切成多個「題目區塊」：

2.1 單題標頭（single）
- Regex: ^Q(\d+)\.\s*$

2.2 題組範圍標頭（range）
- Regex: ^Q(\d+)\s*-\s*Q(\d+)\s*$

切分後，每個區塊需保留：
- block.type ∈ {single, range}
- block.num（單題）或 block.start / block.end（題組）
- block.lines[]（標頭以下到下一個標頭之前的所有行）

3) 區塊標頭輸出（Heading → Markdown）
3.1 若 block.type = single：
- 輸出：## {num}
- 標頭後加 1 個空行

3.2 若 block.type = range：
- 輸出：## {start}-{end}
- 標頭後加 1 個空行

4) 區塊內逐行分類與輸出（Line Classification）
對 block.lines[] 逐行處理；依下列優先序判定該行類型並輸出。

4.1 選項行（Option）
- Regex: ^([A-D])\)\s*(.+)$

輸出格式：
- 若 ANSWER_KEY 存在，且該題號的正解 = 此選項字母：
  {ANS_PREFIX}{Letter}) <span class="tts">{OptionText}
- 否則：
  {Letter}) <span class="tts">{OptionText}

備註：答案前綴放在字母前（例如 *B) ...）。

4.2 題組內子題標頭（Sub-question）
僅在 block.type = range 時啟用。
- Regex: ^Q(\d+)\.\s*$

輸出：
- ### {num}
- 後接 1 個空行

4.3 對話行（Dialogue）
- Regex（寬鬆版）：^([A-Za-z]{1,3}):\s*(.+)$
  例：W: ..., M: ...

輸出：
- {Speaker}: <span class="tts">{Utterance}

4.4 一般敘述行（Narration / Passage / Question stem）
條件：非空行，且不符合 4.1～4.3 任一類型。

輸出：
- <span class="tts">{OriginalLine}

4.5 空行（Blank line）
- 原樣輸出空行（用於分段）

5) 文法/考點強調（Grammar Highlight；可選）
若 HIGHLIGHT_MAP 對該題號有指定片語清單，則在「題幹/敘述行」（4.4 類型）中做片語替換。

5.1 強調語法（二選一，固定用同一種）
- 方案 A（caret）：把片語包成 ^^片語^^
- 方案 B（mark）：把片語包成 ==片語==

5.2 替換策略（二選一，固定）
- 全部替換：同一片語在同一行出現多次則全部包起來
- 只替換第一次：同一片語在同一行只包第一次

6) 輸出排版（Spacing）
6.1 每個 ## 區塊結束後保留至少 1 個空行
6.2 每個 ### 子題標頭後保留 1 個空行
6.3 題幹與選項群之間可保留 1 個空行（建議一致化）

7) 一致性約束與例外（避免格式跑掉）
7.1 若某題在 ANSWER_KEY 中缺值：該題所有選項都不加 ANS_PREFIX
7.2 題組導語（例如 “Questions 53 to 55 refer to ...”）視為一般敘述行 → 套用 4.4
7.3 <span class="tts"> 是否需要補 </span>：
- 建議：全部補齊 </span> 以避免 DOM 範圍不如預期（若你現行環境容錯OK也可維持不補，但要承擔風險）
