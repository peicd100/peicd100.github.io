[2026-02-11] 實作決策
1. GUI 框架：PySide6，主題色使用 #72e3fd。
2. TTS 引擎：edge-tts（免 API key）。
3. 音訊串接：ffmpeg concat，句間與檔間停頓同設定 gap。
4. 增加 CLI 模式：--run-once --voice --rate --gap（方便自動測試）。
5. 錯誤處理：
   - 無數字 md 直接失敗提示。
   - 無 tts 句子的 md 記 warning 並略過。
   - 單句失敗重試 1 次，仍失敗則中止。

[2026-02-11] 安裝與調整
1. conda install -n mkdocs -y -c conda-forge ffmpeg pyside6
2. python -m pip install edge-tts  （使用 mkdocs env 的 python）
3. ffmpeg 編碼器相容性修正：
   - 自動偵測 MP3 encoder（libmp3lame / mp3_mf / mp3）。
   - 針對 mp3_mf 採 44100Hz + stereo + 128k，避免產出無效 mp3。
4. concat 清單改為相對路徑 + 指定 cwd，避免 UNC 路徑讀取問題。
