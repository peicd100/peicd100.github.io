## sort 的 cmp

```cpp
#include<bits/stdc++.h>
using namespace std;
#define pii pair<int,int>
#define all(x) x.begin(),x.end()
#define x first
#define y second

bool cmp(pii a,pii b){
    return a.y<b.y;
}

int main(){
    vector<pii>v={{4,4},{5,2},{2,3},{6,1}};
    sort(all(v),cmp);
    for(pii i:v){
        cout<<i.x<<" "<<i.y<<"\n";
    }
}
```

### Raw string literal 語法

他基本上是寫為：

> R"(<字串內容>)"

請看以下程式碼：

```cpp title="code"
#include <bits/stdc++.h>
using namespace std;
int main(){
    istringstream cin(R"((13 12\n
456 654\n
798))");
    string s;
    while(getline(cin,s)){
        cout<<s<<"%"; //'%'代表換行
    }
}

```

```txt title="output"
(13 12\n%456 654\n%798)%
```


有兩個重點：

- 如果要'()'的話就要額外寫
- 裡面的跳脫字元會被視為一般字元
