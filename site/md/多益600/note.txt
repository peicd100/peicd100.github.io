[2026-02-11] 需求摘要
1. 在 `docs\md\多益600` 新增 `轉換.py`。
2. 提供 GUI 設定：語速、每句間隔時間、聲音樣式，並有「轉換」按鈕。
3. 掃描同層所有 `<數字>.md`，僅抽取每行 `<span class="tts">` 後方文字。
4. 目前需求為同時轉換多個檔案，輸出同檔名 `.mp4`，另外產生 `全.mp4`。
5. 所有 `.mp4` 影片畫面需為黑底，中央顯示檔名文字。
5. 使用 workspace root=`docs\md\多益600`，ENV_NAME=`mkdocs`。

[2026-02-11] 實作決策
1. GUI 使用 PySide6，主題色 `#72e3fd`。
2. TTS 使用 edge-tts（免 API key）。
3. 多檔同時轉換：以 asyncio + semaphore 同時啟動全部數字 md。
4. 單句先存暫存 mp3，句間靜音由 ffmpeg 產生，最後 concat 輸出 mp4（AAC）。
5. 產出檔名：
   - `4.mp4`、`5.mp4`、`6.mp4`、`7.mp4`、`8.mp4`
   - `全.mp4`
6. 錯誤處理：
   - 無數字 md 直接失敗。
   - 無 tts 句子的 md 記 warning 後略過。
   - 單句失敗重試 1 次，仍失敗則整批中止。

[2026-02-11] 安裝與調整
1. `conda install -n mkdocs -y -c conda-forge ffmpeg pyside6`
2. `C:\Users\x1064\.conda\envs\mkdocs\python.exe -m pip install edge-tts`
3. ffmpeg 編碼器處理：
   - 句間靜音使用 MP3 encoder（本機實測 `mp3_mf`）。
   - 最終 mp4 使用 AAC encoder（本機實測 `aac`）。
4. 解決過去 UNC/concat 問題：concat 清單改為相對路徑並指定 cwd。
5. 影片畫面使用 ffmpeg `color + drawtext`，黑底 + 置中檔名文字。
