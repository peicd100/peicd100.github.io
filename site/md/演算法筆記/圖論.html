    BFS

    注意事項！！最常出錯的地方 ：一定要記得宣告vis陣列
    1. q.push後面會加上一個vis=true (所以共兩個)
    2. 判斷if(!vis[i]){ … }
    3. q是要取first

    最基本寫法

    void bfs(int ff){

    queue<int>q;
    bool vis[N];
    
    q.push(ff);  
    vis[ff]=true;             //vis (1/3) push 後面加上一個 vis
    
    while(!q.empty()){
        int f=q.front();q.pop();
        for(int i:v[f]){ 
            if(!vis[i]){      //vis(2/3)
                q.push(i);
                vis[i]=true;  // vis(3/3) push 後面加上一個 vis

                cout<<i;      // 所有的點一定會被放入一次，所以在這處理要做的動作
            
            }
        }
    }
}

    廣度優先，可以看成洪水擴散
    深藍是離開佇列的節點
    淺藍是走到的點
    綠色是加入佇列的點

    步驟：
    1. 首先將第一個點加入佇列
    2. 接著走到第一個點（也就是佇列的第一個），將其子節點依序放入佇列
    3. 刪除佇列中第一個點

    重複2~3直到佇列沒有東西(沒有下一個點)

    P-7-1. 探索距離
    輸入一個有向圖 G 與一個起點 s，請計算由 s 出發可以到達的點數(不包含 s)，並且計算這些可以到達的點與 s 的距離和，假設每個邊的長度均為 1。兩點之間可能有多個邊，邊的起點與終點未必不同。

    Time limit: 1 秒

    輸入格式：
    第一行是兩個正整數 n 與 m，代表圖的點數與邊數，圖的點是以 0~n-1 編號，第二行是 s 的編號，接下來有 m 行，每一行兩個整數 a 與 b 代表一個邊(a,b)。n 不超過 100，m 不超過 4000。

    輸出：
    第一行輸出可以到達的點數，第二行輸出與 s 的距離總和。

    範例輸入：
    7 6
    1
    5 1
    1 3
    1 4
    2 3
    4 6
    6 0

    範例輸出：
    4
    7

    這題比較困難的部分是如何計算高度

    我們可以知道「子節點的高度」為「父節點的高度」+1
    所以dp[子]=dp[父]+1

    另外，這題不能用DFS，因為這是圖不是樹，最短距離要用BFS

    #include<bits/stdc++.h>
using namespace std;
#define nn "\n"
#define N 101

vector<int>v[N];
int ans_1=0;
int ans_2=0;
int d[N]={0};
bool vis[N]={false};


void bfs(int a){
    queue <int>q;
    q.push(a);
    vis[a]=true;  //不要忘記！！！！
    d[a]=0;
    while(!q.empty()){
        int f=q.front();
        q.pop();
        for(int i:v[f]){
            if(!vis[i]){//不要忘記！！！！
                vis[i]=true;//不要忘記！！！！
                d[i]=d[f]+1;
                ans_1++;
                ans_2+=d[i];
                q.push(i);
            }
        }
    }
}

    }

    bfs(a);
    cout<<ans_1<<nn<<ans_2;
    return 0;
}

    vector<bool> visited(n, false);

    P-7-2. 開車蒐集寶物

    https://judge.tcirc.tw/ShowProblem?problemid=d091

    參加一個蒐集寶物的遊戲，你拿到一個地圖，地圖上有 n 個藏寶點，每個藏寶點有若干價值的寶物，由於你的團隊是最頂尖的，只要能到達藏寶點一定可以取得該藏寶點的寶藏。從地圖上看得到一共有 m 條道路，每條道路連接兩個藏寶點，而且每條道路都是雙向可以通行的。在遊戲的一開始，你可以要求直升機將你的團隊運送到某個藏
    寶點，而且你可以獲得一部車與充足的油料，但是直升機的載送只有一次，所以你必須決定要從哪裡開始才可以獲得最多的寶藏總價值。

    }

    }

            } else {

            } else {
                output[f] = 0;
            }

    Dijkstra 演算法用來計算一個圖中一點到其他點的最短路徑

    1. 為什麼 pop 出來就能確定

    Dijkstra Algorithm(Dijkstra 演算法) 解的是 Single-Source Shortest Path(單源最短路徑)：從一個起點 s 到所有點的最短距離。它要求邊權重是 non-negative(非負數)，也就是不能有負邊；這點是它正確性的核心限制。(CP Algorithms)

    你可以把 Dijkstra 想成：

    BFS 是每條邊成本都一樣時的最短路；Dijkstra 是每條邊成本不一樣、但都不會是負數時的 BFS。

    2. 核心概念：dist[v] 不是答案，一開始只是「目前找到的最好答案」

    我們先定義：

    dist[v] = 從起點 s 到 v，目前已知的最短距離

    注意，是「目前已知」，不是一開始就保證正確。

    一開始：

    dist[s] = 0
dist[其他點] = INF

    然後每次從 Priority Queue(優先佇列) 裡面拿出 目前 dist 最小的點。

    這一步是整個 Dijkstra 最重要的貪婪選擇：

    目前所有還沒確定的點裡，誰的 dist 最小，就先確定誰。

    3. 為什麼「最小的點」可以直接確定？

    假設現在 Priority Queue 裡面最小的是點 u，距離是 dist[u]。

    你可能會想：

    會不會之後繞一條路，讓 u 變更短？

    Dijkstra 的回答是：不會。

    原因是所有邊權重都是非負數。

    如果之後要找到一條更短的路到 u，那條路一定會先經過某個還沒處理的點 x，再走到 u。

    可是因為 u 已經是目前距離最小的點，所以：

    dist[u] <= dist[x]

    而從 x 再走一些邊到 u，邊權重又不會是負數，所以距離只會增加或不變：

    dist[x] + 後面的邊 >= dist[x] >= dist[u]

    所以不可能比 dist[u] 更短。

    這就是 Dijkstra 的核心 Invariant(不變量)：

    每次從 Priority Queue 取出的最小距離點，它的最短距離就已經確定了。

    4. Relaxation(鬆弛) 是什麼？

    Relaxation(鬆弛) 其實就是檢查：

    「如果我先到 u，再從 u 走到 v，會不會比原本到 v 的方法更短？」

    公式是：

    if (dist[u] + w < dist[v]) {
    dist[v] = dist[u] + w;
}

    生活化例子：

    你目前知道：

    家 -> 學校 = 20 分鐘

    現在發現：

    家 -> 捷運站 = 5 分鐘
捷運站 -> 學校 = 10 分鐘

    所以：

    家 -> 捷運站 -> 學校 = 15 分鐘

    比原本的 20 分鐘短，於是更新：

    dist[學校] = 15

    這就是 Relaxation(鬆弛)。

    9. 你可以這樣記 Dijkstra

    不要背「流程」，要背這個核心：

    dist[v] = 目前找到的最短路

每次挑 dist 最小的點 u

因為邊權非負，
所以其他還沒處理的點不可能繞出更短路回來救 u

因此 u 的答案確定

然後用 u 去更新鄰居

    一句話版：

    Dijkstra 每次確定離起點最近的未確定點，然後用這個點去改善其他點的距離。

    10. 最常見錯誤

    10.1 把點 push 進 Priority Queue 時就當成確定

    錯誤想法：

    點 v 被 push 進 pq，所以 v 的答案確定了

    這是錯的。

    正確是：

    點 v 從 pq pop 出來，而且它是目前最新 dist，才確定

    10.2 有負邊還用 Dijkstra

    如果有負邊，Dijkstra 的「pop 出來就確定」會壞掉。

    例子：

    1 -> 2 = 2
1 -> 3 = 5
3 -> 2 = -10

    一開始看起來：

    dist[2] = 2
dist[3] = 5

    Dijkstra 會先確定 2。

    但其實：

    1 -> 3 -> 2 = -5

    更短。

    所以負邊要用 Bellman-Ford Algorithm(Bellman-Ford 演算法)、SPFA，或其他處理負權圖的方法。Dijkstra 標準版本的前提是 non-negative edge weights(非負邊權)。(CP Algorithms)

    10.3 priority_queue 預設是 Max-Heap

    C++ 預設：

    priority_queue<int> pq;

    是最大值優先。

    Dijkstra 要 Min-Heap(最小堆)，所以要寫：

    priority_queue<
    pair<ll, int>,
    vector<pair<ll, int>>,
    greater<pair<ll, int>>
> pq;

    11. 最後用一句直覺收斂

    Dijkstra 其實不是魔法。

    它只是一直問：

    目前我最有把握、距離最短的點是誰？

    然後因為所有路都不會有負成本，所以：

    更遠的點不可能繞一圈讓這個最近的點變更近

    因此最近的點可以被安全確定。

    你真正要抓住的是這句：

    非負邊權保證：目前最小的暫定距離，未來不可能再變小。

        v[y].push_back({x, w});  // 雙向

        pii,
        vector<pii>,
        greater<pii>>

    1. 併查集在解決什麼問題

    Disjoint Set Union(併查集)，也常叫 Union-Find(合併查找)，專門處理這種問題：

    有很多個元素，我們需要一直做兩件事：

    1. 把兩個元素所在的群組合併
    2. 查兩個元素是否在同一個群組

    例如：

    1 和 2 是朋友
2 和 3 是朋友
問：1 和 3 是不是同一群？

    答案是：是。因為：

    1 -- 2 -- 3

    所以 1、2、3 屬於同一個集合。

    併查集的標準做法會用 rooted tree(有根樹) 表示集合，每個集合用一個 representative(代表點)，也就是 root(根節點) 代表整群。Boost 的 disjoint_sets 文件也把這個資料結構描述為用 parent tree(父節點樹) 維護不相交集合，並搭配 path compression(路徑壓縮) 和 union by rank(依秩合併) 加速操作。(boost.org)

    2. 核心原理

    我們開一個陣列：

    parent[i]

    意思是：

    i 的爸爸是 parent[i]

    一開始每個人都是自己一群，所以：

    parent[i] = i;

    例如有 5 個點：

    1  2  3  4  5

    一開始：

    parent[1] = 1
parent[2] = 2
parent[3] = 3
parent[4] = 4
parent[5] = 5

    每個點自己就是 root(根)。

    3. find_root 是什麼

    find_root(x) 的目的：

    找出 x 所在集合的 root(根節點)。

    例如：

    1 -> 2 -> 3

    代表：

    parent[1] = 2;
parent[2] = 3;
parent[3] = 3;

    那麼：

    find_root(1)

    會一路往上找：

    1 的爸爸是 2
2 的爸爸是 3
3 的爸爸是 3，所以 3 是 root

    所以：

    find_root(1) == 3

    4. path compression(路徑壓縮)

    如果每次都慢慢往上找，樹太高會變慢。

    所以我們找 root 的時候，順便把路徑上的點直接接到 root。

    原本：

    1 -> 2 -> 3 -> 4

    執行：

    find_root(1)

    5. 合併兩個集合

    假設要合併 a 和 b。

    錯誤想法是：

    parent[a] = b;

    這樣不穩，因為 a 不一定是 root。

    正確做法是：

    int ra = find_root(a);
int rb = find_root(b);

    意思是：

    ra = a 那一群的代表
rb = b 那一群的代表

    如果：

    ra == rb

    代表它們本來就在同一群，不用合併。

    如果：

    ra != rb

    就把其中一個 root 接到另一個 root 底下。

    6. union by size(依大小合併)

    我們再開一個：

    sz[i]

    意思是：

    如果 i 是 root，sz[i] 表示這一群有幾個元素

    合併時，把小集合接到大集合下面，樹會比較矮。

    if (sz[ra] < sz[rb]) swap(ra, rb);

parent[rb] = ra;
sz[ra] += sz[rb];

    意思是：

    如果 ra 那群比較小，就交換 ra 和 rb
保證 ra 是比較大的那群
然後把 rb 接到 ra 底下

    搭配 path compression(路徑壓縮) 後，併查集的操作非常接近 O(1)。較正式地說，經典分析會用 inverse Ackermann function(反阿克曼函數) 描述其成長，非常慢；Tarjan 的集合合併演算法分析就是這類複雜度的代表性來源。(OA Monitor Ireland)

    法二：Prim 演算法

    Prim 演算法教學

    1. 這題用 Prim 在做什麼

    這題 d098 要你找 Minimum Spanning Tree(最小生成樹)：在一張 undirected weighted graph(無向加權圖) 裡，用一些邊把所有點連起來，並讓總邊權最小；如果圖不連通，輸出 -1。題目點編號是 0 ~ n - 1，邊權非負，n <= 1e4、m <= 1e5。(TCIRC Judge 串中電研OJ)

    Prim's Algorithm(普里姆演算法) 的核心想法是：

    從某一個點開始，慢慢把 MST 長大。
每次都選一條「從已經在 MST 裡的點」連到「還沒進 MST 的點」的最便宜邊。

    CP-Algorithms 對 Prim 的描述也是：一開始生成樹只包含任意選的一個點，之後每次加入一條連到未選點的最小權重邊。(競賽程式設計演算法)

    2. 生活化理解：Prim 像在鋪電線

    想像每個點是村莊，每條邊是兩村之間鋪電線的成本。

    一開始我們先選一個村莊，例如 0：

    已通電：0
未通電：1, 2, 3, ...

    接著每一步都問：

    從「已通電的村莊」往外接一個「還沒通電的村莊」，
哪一條線最便宜？

    找到最便宜的，就接上去。

    接上去以後，已通電村莊變多，可以選的邊也變多。

    所以 Prim 不是在找「從 0 到每個點最短路」，而是在找：

    每次用最便宜的一條邊，把一個新點納入 MST。

    3. Prim 和 Dijkstra 最容易混的地方

    你之前有 Dijkstra 程式，所以這裡要特別分清楚。

    3.1 Dijkstra 的 dist[v]
    dist[v] = 從起點 s 走到 v 的最短路徑總長

    更新時用：

    dist[v] = dist[u] + w;

    因為它是「一路從起點累加過來」。

    3.2 Prim 的 dist[v]

    在 Prim 裡我們也常開一個 dist 或 key，但意思不同：

    dist[v] = 目前把 v 接進 MST 的最便宜單條邊成本

    更新時只用：

    dist[v] = w;

    不是：

    dist[v] = dist[u] + w;

    因為 MST 不管「從起點走到 v 的路徑總長」，它只在意「把 v 接進目前這棵樹的那條邊多少錢」。

    USACO Guide 對 Prim 的 priority queue 寫法也說，從 priority queue 取出最接近 MST 的點，然後把它的鄰居加入 priority queue；起點可任選。([USACO 指南][3])

    4. Prim 的核心不變量

    Prim 每一步都維持這個狀態：

    vis[v] = true 代表 v 已經被加入 MST
vis[v] = false 代表 v 還沒加入 MST

    priority queue 裡面放的是：

    {接進 MST 的邊權, 點}

    也就是：

    {w, v}

    不是 Dijkstra 的：

    {從起點到 v 的距離, v}

    這題點編號是：

    0 ~ n - 1

    Prim 的起點可以任選，所以我們直接選：

    pq.push({0, 0});

    意思是：

    把點 0 當作第一個進 MST 的點，成本是 0。

    注意這個 0 成本不是一條真的邊，只是讓演算法從點 0 開始。

    假設圖長這樣：

    0 -- 1，權重 1

    從 0 開始。

    一開始：

    MST 裡：0
pq 裡：{0,0}
ans = 0

    取出 {0,0}，把 0 加入 MST。

    把 0 的邊丟進 pq：

    {1,1}
{2,2}

    接著取最小 {1,1}，把 1 加入 MST：

    ans = 1
MST 裡：0, 1

    把 1 的邊丟進 pq，其中 1-2 權重 1：

    {1,2}
{2,2}

    ans = 2

    0-1，權重 1

    8. 這題的 Prim 寫法，不用 struct

    這份寫法最適合你現在理解，因為 priority queue 裡只存：

    {邊權, 點}

    完整程式：

    #include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int n, m;
    cin >> n >> m;

    vector<vector<pair<int, int>>> g(n);

    for (int i = 0; i < m; i++) {
        int u, v, w;
        cin >> u >> v >> w;

        // 題目是無向圖，所以兩邊都要加
        g[u].push_back({v, w});
        g[v].push_back({u, w});
    }

    priority_queue<
        pair<int, int>,
        vector<pair<int, int>>,
        greater<pair<int, int>>
    > pq;

    vector<int> vis(n, 0);

    long long ans = 0;
    int cnt = 0;

    // Prim 起點可以任選；這題點是 0 ~ n - 1，所以從 0 開始
    pq.push({0, 0});  // {接進 MST 的成本, 點}

    while (!pq.empty()) {
        auto cur = pq.top();
        pq.pop();

        int d = cur.first;
        int u = cur.second;

        // 如果 u 已經進 MST，這筆資料是舊的，跳過
        if (vis[u]) continue;

        // 把 u 加入 MST
        vis[u] = 1;
        ans += d;
        cnt++;

        // 把 u 連出去、能接到新點的邊放進 pq
        for (auto e : g[u]) {
            int v = e.first;
            int w = e.second;

            if (!vis[v]) {
                pq.push({w, v});
            }
        }
    }

    if (cnt == n) {
        cout << ans << "\n";
    } else {
        cout << -1 << "\n";
    }

    return 0;
}

    vector<pair<int, int>>,
    greater<pair<int, int>>
> pq;

    這是 min-heap(小根堆)。

    裡面每筆資料是：

    {d, u}

    意思是：

    目前有一條成本 d 的邊，可以把 u 接進 MST
    9.3 為什麼 pq.push({0, 0})
    pq.push({0, 0});

    意思是：

    從點 0 開始。
把 0 加進 MST 的成本先當作 0。

    這不是說有一條權重 0 的邊，而是演算法啟動用的假成本。

    9.4 為什麼要 vis
    if (vis[u]) continue;

    因為同一個點可能被很多條邊推進 priority queue。

    例如：

    0 -- 2，權重 10
1 -- 2，權重 3

    點 2 可能先被 {10, 2} 推進 pq，後來又被 {3, 2} 推進 pq。

    如果 {3, 2} 先被拿出來，2 已經進 MST 了，之後 {10, 2} 再被拿出來時，就要跳過。

    10. 為什麼這版不用 dist

    Prim 有兩種常見寫法：

    10.1 懶惰版 Lazy Prim

    也就是我上面給你的版本。

    它的做法是：

    看到一條可以連到未拜訪點的邊，就丟進 pq。
之後如果拿出來時那個點已經進 MST，就跳過。

    優點：

    比較好懂，程式短。

    缺點：

    pq 裡會有一些舊資料。

    但這題 m <= 1e5，完全可以接受。(TCIRC Judge 串中電研OJ)

    10.2 類 Dijkstra 版 Prim

    也可以寫 dist[v]：

    dist[v] = 把 v 接進 MST 的目前最小邊權

    更新時：

    if (!vis[v] && w < dist[v]) {
    dist[v] = w;
    pq.push({dist[v], v});
}

    這比較像你之前的 Dijkstra，但初學我建議先看 Lazy Prim，因為更直接：

    把所有候選邊丟進 pq，每次拿最小的。

    11. Lazy Prim 的核心記法

    你可以把它背成 4 句：

    1. 從任一點開始，先 push {0, 起點}
2. 每次從 pq 拿出最便宜的候選邊
3. 如果這個點還沒進 MST，就收下它，ans += 邊權
4. 把這個點連到未拜訪點的邊都丟進 pq

    12. 跟 Kruskal 的差別

    演算法 怎麼選邊 需要 DSU 嗎 起點
    Kruskal 全部邊排序，從小到大選不成環的邊 需要 沒有
    Prim 從目前 MST 往外長，每次選最便宜的外接邊 不需要 可以任選

    這題兩種都可以。你剛學 DSU，所以 Kruskal 很直覺；但如果你想練 priority queue，Prim 也很適合。

    13. 你最容易寫錯的地方

    13.1 忘記無向圖要加兩邊

    錯誤：

    g[u].push_back({v, w});

    正確：

    g[u].push_back({v, w});
g[v].push_back({u, w});
    13.2 把 Prim 寫成 Dijkstra

    錯誤：

    pq.push({d + w, v});

    這是 Dijkstra 味道。

    Prim 要放單條邊權：

    pq.push({w, v});

    因為 Prim 每次在比的是：

    哪條邊最便宜可以接新點

    不是：

    從起點到 v 的總距離是多少
    13.3 最後檢查條件寫錯

    Kruskal 檢查：

    cnt == n - 1

    因為 Kruskal 的 cnt 通常是「選了幾條邊」。

    Prim 這份程式裡檢查：

    cnt == n

    因為這裡的 cnt 是「有幾個點進入 MST」。

    兩個不要搞混。

    使用這方法找出所有最短路徑，最後加在一起。

    注意

    比較需要注意的是對於相同的點不要 push 之後就 vis = 1，應該要全部都加到 pq 中，然後拿出來 vis == 1 跳過、vis =1。

    #include <bits/stdc++.h>
using namespace std;

#define pii pair<int, int>

int main() {
    int n, m;
    cin >> n >> m;  // 點:0~n, 操作:m

    vector<int> vis(n);
    vector<vector<pii>> vec(n);

    int x, y, w, u, d, v;
    for (int i = 0; i < m; i++) {
        cin >> x >> y >> w;
        vec[x].push_back({y, w});
        vec[y].push_back({x, w});  // 雙向
    }

    priority_queue<
        pii,
        vector<pii>,
        greater<pii>>
        pq;

    pq.push({0, 0});  // 隨便找一個起點

    int ans = 0, cnt = 0;
    while (!pq.empty()) {
        tie(d, u) = pq.top();
        pq.pop();

        // 如果 u 已經進 MST，這筆資料是舊的，跳過
        if (vis[u]) continue;
        vis[u] = 1;
        ans += d;
        cnt++;

        for (pii pp : vec[u]) {
            tie(v, w) = pp;

            if (!vis[v]) {
                pq.push({w, v});
            }
        }
    }

    if (cnt == n) {
        cout << ans;
    } else {
        cout << -1;
    }

    return 0;
}
